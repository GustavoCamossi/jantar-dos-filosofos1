O Jantar dos Filósofos

Cinco filósofos, cinco hashis (os palitos japoneses), e cada um precisa de dois para comer. Siga a aula guiada passo a passo ou teste as estratégias por conta própria.

      Código da estratégia

      Código do filósofo i, com N = 5: Sócrates é 0, Platão 1, Aristóteles 2, Hipátia 3 e Descartes 4. As bolinhas com a inicial mostram em que linha cada um está agora.

      Problema proposto por Dijkstra e reformulado por Hoare como o jantar dos filósofos. As quatro condições são as de Coffman (1971). Código no estilo de Tanenbaum, Sistemas Operacionais Modernos. Hashi é o palito japonês. Retratos são ilustrações livres.
